Something went wrong?

Tell an organizer in Discord which step you’re on and paste the exact error. Never paste keys, tokens or upload links.

My AI key stopped working
Run the step 2 setup again, which checks the key. If it still fails, show the error to an organizer. “Budget exceeded” with little use is often a false alarm: wait a minute and retry.
“access_denied: This server is open only to invited accounts”
Sign out of Xsolla Login in your browser and sign in with your registered email. If that fails, tell an organizer which email you used and publish with Option B for now.
The tools stop working or ask me to sign in again
Type /mcp, choose xsolla and authenticate again. With Codex, run codex mcp logout xsolla, then codex mcp login xsolla.
get_account says canPublish: false
Fix each item it lists (verify your email, accept the developer terms, set an author name), then ask it to check again.
Build “issue”, upload error 403 or 422
Usually index.html is inside a subfolder of the zip: re-zip with it at the top. A 403 means the upload link expired after 5 minutes: ask for a new one. A 422 lists what’s missing.
“Two games cannot share a title”
Someone already uses that title. Pick another.
My game isn’t on the jam page
Wait 2–5 minutes and refresh. Check it was created with the jam code and submitted. Create the game during the submission window to avoid duplicates.
